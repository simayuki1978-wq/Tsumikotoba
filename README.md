# つみことば

毎日ことばを積み重ねる日本語学習アプリ。基礎500語（動詞・形容詞・名詞）＋漢字122字を、
**1日10単語・漢字3つ**のペースで新規学習し、**忘却曲線（1→3→7→14→30→90日）**に基づく
間隔反復で復習していく、ゲーム要素つきの単語帳です。

外部ライブラリ・ビルド不要のプレーンな HTML / CSS / JavaScript のみで動作します。
データはブラウザの `localStorage` に保存されるため、サーバーやアカウント登録は不要です。

## 特徴

- 🎯 **きょうのクエスト**：新しい単語10個・漢字3つ・復習、をリング表示で管理
- 🗂️ **フラッシュカード**：単語／漢字をタップしてめくり、3段階で自己評価
- ❓ **4択クイズ**：意味・読み方をランダム出題
- 🔄 **動詞活用ドリル**：ない形・ます形・て形・た形・ば形・よう形を他の活用形をひっかけ選択肢にして出題
- 🔥 **ストリーク＆XP／レベル**、コンボ表示などのゲーミフィケーション
- 🎎 **だるま帳**：連続学習日数（3/7/14/30/60/100/200/365日）に応じてスタンプ収集
- 🔍 **さがす**：622語すべてを検索・閲覧できる辞書ビュー
- 👤 **プロフィール切り替え**：同じ端末を複数人で使うとき、名前とアイコンで学習記録を分けられます（後述の通りパスワード保護はありません）

## 音声（任意）

VOICEVOX で作った MP3 を `audio/` フォルダに置くと、フラッシュカード・クイズ・ドリル・さがすページに 🔊 ボタンが出ます。
`audio/manifest.json` がない場合、🔊 ボタンは表示されません（アプリはそのまま使えます）。

**生成手順**（手元のPCで実行）
1. VOICEVOX を起動する（エンジンが `http://127.0.0.1:50021` で動きます）
2. ffmpeg と Python 3.8 以上を用意する
3. リポジトリのルートで実行する
   ```
   python tools/generate_audio.py
   python tools/generate_audio.py --female 春日部つむぎ --male 青山龍星   # キャラクター変更
   python tools/generate_audio.py --limit 10                              # 試しに10件だけ
   ```
4. できた `audio/` フォルダごと GitHub にアップロードする

- 女性・男性の声を1語ごとに交互に使います（単語と例文は同じ声）
- 単語は `audio/v1.mp3`、例文は `audio/v1_ex.mp3`、漢字は熟語例の読みを `audio/k1_ex.mp3` に出力します
- 読み間違いは `audio_overrides.json`（例：`{"v1": {"w": "たべる"}}`）で読ませる文字列を直せます
- クイズで答えが分かってしまう場面（答えが単語・読みの問題）では、回答前に 🔊 を出しません

**クレジット表記と利用規約**
画面下部に `audio/manifest.json` の内容（例：音声：VOICEVOX:四国めたん / VOICEVOX:玄野武宏）を自動表示します。
キャラクターごとに利用規約が異なるため、使用するキャラクターの最新の規約を公式サイトで確認してください。

## ログイン機能について

このアプリは完全に静的（サーバーなし）なので、**本物のログイン（パスワード認証）は実装していません**。
代わりに、次のような「端末内プロフィール切り替え」を入れています。

- 初回起動時になまえとアイコンを選ぶ（パスワード不要）
- 同じ端末・同じブラウザ内で、複数人分の学習記録（単語の進捗・XP・ストリークなど）を分けて保存
- 画面右上のプロフィールチップから、いつでも切り替え・追加・削除が可能

**注意点**
- パスワードによる保護は一切ありません。同じ端末を使える人なら誰でも他の人のプロフィールに切り替えて見たり、削除したりできます。
- 端末をまたいだ同期はしません（スマホとPCでは別々の記録になります）。
- 本格的な複数端末同期・アカウント保護が必要な場合は、Googleログイン等のOAuth＋Firebase/Supabaseのようなバックエンドサービスの追加が別途必要です（このリポジトリのままでは実現できません）。

## ファイル構成

```
index.html   ページ本体（CSS/JSを読み込むだけ）
style.css    デザイン（ポップ＆ゲーム風、ライト/ダーク自動対応）
app.js       アプリのロジック（SRS・出題・画面描画など）
data.js      単語500語＋漢字122字のデータ（WORDS / KANJI 定数）
```

## 使い方

### ローカルで開く
`index.html` をブラウザで直接開くだけで動作します（サーバー不要）。

### GitHub Pages で公開する
1. このリポジトリを GitHub にプッシュ
2. Settings → Pages → Branch を `main`（`/root`）に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 学習データについて

`data.js` の単語・漢字データは、アップロードいただいた基礎データベース（Excelファイル）から
書き出したものです。内容を差し替えたい場合は `data.js` 内の `WORDS` / `KANJI` 配列を編集してください。
それぞれの項目の形は次のとおりです。

```js
// WORDS の1件（動詞の例。形容詞・名詞には conj は不要）
{ id, pos, word, reading, meaning, level, type, example, conj: { nai, masu, dict, ba, you, te, ta } }

// KANJI の1件
{ id, char, on, kun, meaning, strokes, compound, level }
```
